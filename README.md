🚀 Project Title
Personal Portfolio Website – Shaikh Mohammed Yusuf

📌 Overview
This is a modern, fully responsive personal portfolio website developed to showcase my:
•Skills
•Projects
•Hackathon achievements
•Contact information

The portfolio is designed with a premium UI/UX, smooth animations, and a clean layout to represent my professional identity as a Software Developer & Cybersecurity Enthusiast.

🎯 Objective
The main goal of this project is:
•To create a strong online presence
•To showcase real-world projects with live demos
•To highlight technical skills and achievements
•To provide an easy way for recruiters or  collaborators to connect

🛠️ Technologies Used
⚛️ Frontend
•React.js → Component-based UI development
•Vite → Fast build tool for React (better than CRA)
•JavaScript (ES6+) → Core logic
•HTML5 & CSS3 → Structure and styling

🎨 Styling & UI
•Tailwind CSS / Custom CSS → Modern responsive design
•Glassmorphism UI → Transparent cards with blur effect
•Gradient Colors → Premium visual feel
•Flexbox & Grid → Layout management

🎞️ Animations
•Framer Motion → Smooth animations (fade, slide, hover effects)
•Scroll-based animations for sections

🌐 Deployment
•Vercel → Hosting and automatic deployment
•Connected with GitHub for CI/CD

🔗 Version Control
•Git & GitHub
•Code management
•Version tracking
•Deployment integration
